What it is

A self-picked follow-up I built after studying Stanford CS329 Self-Improving AI Agents and Dave Ebbelaar’s agent video. A local-first open-source agent you can run on your machine today.

Verbal RL, not fine-tuning

Weights never change. Lessons and skills are retrieved into the act system prompt. The agent improves by writing durable memories from feedback. Limit: it cannot invent abilities the base model lacks. Without /good / /bad, “learning” is only fact accumulation.

Why local extractors need the extra loop

Mem0 Cloud is cleaner; locally you need hybrid retrieve (vector + lexical), domain gating so pytest prefs do not leak into “capital of France,” /purge, /consolidate, and fact correction on feedback notes. That is the engineering, not the tutorial.

Technology stack

Python Ollama Mem0 Qdrant Docker Verbal RL

Hybrid retrieve (keep rules)

Hard keep if vector ≥ 0.5. Soft keep if vector ≥ 0.28 and lexical overlap ≥ 0.12. Identity queries get a lower floor plus query expansion (“where do I live” → “user lives in city location”). Assistant-junk and domain-mismatched tool prefs are dropped.

Limits

Improves via memory, not weight updates. Local extractors are noisier than Mem0 Cloud, use feedback and consolidation to keep the store clean. Greetings are skipped so Mem0 does not invent “User greeted…” noise.

Local → Production

Same loop, different config

Future scope: the shipped path is CLI + Ollama + Mem0 + Qdrant on-disk or Docker. The same retrieve → act → evaluate → write loop scales by swapping config, FastAPI with per-user user_id, a hosted LLM or vLLM, managed Qdrant/Pinecone, and cron for /promote · /consolidate not by rewriting the agent. Keep embed dims at 1024 or wipe the collection.
